# 匿名端到端示例

> 本目录全部为**合成示例数据**，用于展示工作流，不对应任何真实候选人、招聘岗位或 OPPO 内部信息。

这个示例演示“资料整理 → 岗位筛选 → 定向改写 → A4 排版”的完整交接。候选人林然希望申请 AI 产品岗位；Agent 对两个公开风格的虚构 JD 评分，把“AI 产品经理”作为第一选择，把“数据产品经理”作为第二选择，并针对第一选择生成简历。

## 1. 整理个人资料

输入文件：[`profile-summary.json`](profile-summary.json)

Prompt：

> 使用 career-profile，把这份合成资料按个人档案、教育经历、实习经历、经历素材、项目经历、技能与工具、目标岗位、荣誉奖项归类。先给我写入预览，不要立即写飞书。

## 2. 筛选岗位

输入文件：[`jobs.json`](jobs.json)

Prompt：

> 使用 job-screening，结合个人资料评估这两个岗位，给出 0–100 分、匹配等级、匹配点、短板、推荐序号和投递建议。先预览，再写入推荐岗位明细。

结果：

| 推荐序号 | 岗位 | 分数 | 等级 | 结论 |
|---:|---|---:|:---:|---|
| 1 | AI 产品经理 | 86 | A | AI 应用闭环、用户研究与数据分析证据较完整 |
| 2 | 数据产品经理 | 74 | B | 分析能力匹配，但企业级数据平台经验偏弱 |

## 3. 改写简历

输出文件：[`resume.md`](resume.md)

Prompt：

> 使用 resume-writing，面向第一优先的 AI 产品经理岗位生成一页中文简历。只使用已确认事实，不补造数字；同时输出 Markdown 和 JSON。

## 4. 排版与导出

可编辑页面：[`resume-page/index.html`](resume-page/index.html)

Prompt：

> 使用 resume-layout，把已确认的 resume.md 排成一页 A4 可编辑网页，检查溢出并导出 PDF。

打开网页后可以直接点击“开始编辑”，独立微调文字、行距和整体字号，再用浏览器“打印 / 导出 PDF”。整体字号范围为 92%–108%；恢复旧备份时，示例页会保留模板中当前使用的照片资源。
