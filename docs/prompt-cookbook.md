# Prompt 使用手册

以下示例中的飞书链接应替换为用户自己的链接；不要把链接写入公开仓库。

## 1. career-workflow

**适用场景：** 一次完成两个或更多阶段。

**必填输入：** 当前目标、相关 Base 链接、目标公司/岗位或 JD。

**可选输入：** 推荐数量、城市、页数、输出目录、隐私限制、照片。

**最短 Prompt：**

> 连接我的个人信息库和岗位库，筛选最适合我的两个岗位，并为第一优先岗位生成一页简历。

**完整 Prompt：**

> 使用 career-workflow。个人信息库和岗位库链接我会在本次对话提供。目标是 AI 产品经理，优先成都和深圳，从未投递且仍开放的岗位中推荐 5 个。先展示评分和拟写入内容，确认后写回岗位库；再为第一优先岗位生成一页中文简历。只使用已确认事实，文案确认后再排版为可编辑 A4 网页并导出 PDF。

**输出：** 阶段状态、岗位排序、飞书写入结果、简历 Markdown/JSON、网页/PDF 路径和验证结果。

## 2. career-profile

**适用场景：** 创建信息库、导入简历、补充项目或审计已有资料。

**必填输入：** 个人信息库链接；简历、项目材料或本人描述。

**可选输入：** 目标方向、指定表、只读模式、隐私限制。

**最短 Prompt：**

> 读取这份简历，把已确认的信息整理进我的个人信息库；不确定的内容先问我。

**完整 Prompt：**

> 使用 career-profile，只读检查我的个人求职信息库。结合我提供的简历和项目记录，按 8 张表归类事实；区分已确认、待补充和待确认。先输出缺失信息与拟写入预览，不要自行补数字或修改飞书。等我确认后再新增或更新记录。

**输出：** 事实台账、缺失问题、写入预览和确认后的写入结果。

**是否写飞书：** 会，但必须先确认。

## 3. job-screening

**适用场景：** 收集、核验、比较、评分和排序岗位。

**必填输入：** 两个 Base 链接；岗位链接、JD 文本或岗位库筛选范围。

**可选输入：** 方向、城市、公司、数量、截止时间和排除条件。

**最短 Prompt：**

> 从岗位库筛选最适合我的 5 个 AI 产品岗位，并解释匹配点和短板。

**完整 Prompt：**

> 使用 job-screening。读取个人信息库中已确认的经历，对岗位库里仍开放、未投递、工作地点包含成都或深圳的岗位做全量筛选。按核心任务、经历证据、技能工具、行业场景、硬性门槛和申请时效评分，给出前 5 名。先展示排序、依据、短板和拟写入字段，确认后更新岗位清单与推荐岗位明细。

**输出：** 0–100 分、S/A/B/C 等级、匹配点、短板、优先级、推荐序号和投递建议。

**是否写飞书：** 会，但必须先确认。

## 4. resume-writing

**适用场景：** 从零撰写、诊断、JD 定向改写、事实挖掘和最终质检。

**必填输入：** 选定岗位或 JD；个人信息库链接。

**可选输入：** 旧简历、页数、语言、隐私限制和强化方向。

**最短 Prompt：**

> 针对岗位库中的第一优先岗位改写一页中文简历，只使用已确认事实。

**完整 Prompt：**

> 使用 resume-writing。读取个人信息库的 8 张表和推荐岗位明细中的第一优先岗位，先建立岗位—证据映射。核心条目缺少场景、个人措施或结果时先问我，不要用泛化文字补齐。输出一页中文简历 Markdown、结构化 JSON、缺失信息表和六维评分。未经确认的数字、技能和上线状态不能进入终稿。

**输出：** Markdown、JSON、事实口径、缺失信息和 30 分质量评分。

**是否写飞书：** 默认只读；可按用户明确要求把版本路径写回岗位库。

## 5. resume-layout

**适用场景：** 把已确认内容制作成可编辑 A4 网页、微调间距或导出 PDF。

**必填输入：** 已确认的 `resume.md` 或 `resume.json`；输出目录。

**可选输入：** 照片、参考样式和密度偏好。

**最短 Prompt：**

> 把已确认的简历排成一页 A4 网页，保留编辑、间距调整和 PDF 导出。

**完整 Prompt：**

> 使用 resume-layout。以已确认的 resume.json 为唯一内容来源，生成白色一页 A4 简历。照片保持原比例，使用真实列表符号，个人荣誉与技能合并。保留浏览器编辑、行距与整体字号独立调节、自动保存、JSON 备份恢复和打印/PDF。整体字号范围限定为 92%–108%，恢复旧备份时不得覆盖当前照片。完成后运行结构与页面填充校验；有溢出或大面积留白时继续调整，不要缩小到不可读字号。

**输出：** 可编辑网页、内容备份、PDF 和验证结果。

**是否写飞书：** 否；只生成本地文件。

## 推荐的下一步 Prompt

- 信息录入后：`根据个人信息库，找出最影响 AI 产品岗位简历的 5 个事实缺口。`
- 岗位筛选后：`为第一优先和第二优先岗位分别生成岗位—证据映射。`
- 简历改写后：`逐条核查数字口径、个人所有权和项目状态。`
- 排版后：`检查一页 A4 填充、打印效果、编辑保存和 JSON 恢复。`
